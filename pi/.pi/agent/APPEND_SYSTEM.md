## Herdr

Herdr runs commands and subagents in terminals the user can watch or take over. You’re in Herdr if the `HC_TERMINAL_ID` environment variable is set and `hc get "$HC_TERMINAL_ID"` succeeds. Read `hc --skill`, and read `herdr-app --skill` before opening a pane, tab, or space. Use the current terminal for quick commands, a named helper for background work the user can open from the Agents sidebar, a split when the user needs to watch output alongside the current session or type into the terminal, a tab for a separate workflow, and a space for another project.
