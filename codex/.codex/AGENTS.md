## Herdr

If `HC_TERMINAL_ID` is set and `hc get "$HC_TERMINAL_ID"` succeeds, read `hc --skill`. Use Herdr for long-running or interactive commands and named helper agents for independent work when delegation is allowed.

Keep background work out of the layout by default. Use a pane in the current tab for related work the user needs to see or interact with, and a new tab for a separate workflow the user wants to follow. Read `herdr-app --skill` before changing the layout. Let the user enter passwords directly in the terminal.
